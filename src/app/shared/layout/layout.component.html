GitHub Models API Token

As Super Admin, you can configure the GitHub token for testing. For production, set the GITHUB_TOKEN environment variable in Netlify.

  1. Visit GitHub Settings → Tokens
  2. Click "Generate new token (classic)"
  3. Select scopes: repo
  4. Copy the token (starts with ghp_)
  5. Paste it below and click Save
💡 For Production: Set GITHUB_TOKEN in Netlify environment variables so all users can access AI features without manual configuration.
